## 🤔 这是什么？

这是一个**商品报价管理查询系统**，可以帮助您：

- ✅ **管理商品** — 导入 Excel 表格，集中管理 30 个字段的商品信息（快查型号、品牌、品类、各类价格、规格、参数等）
- ✅ **快速查询** — 像聊天一样输入自然语言就能查到想要的商品报价
- ✅ **智能筛选** — 通过下拉菜单快速组合筛选品类、品牌、价格区间、折扣率
- ✅ **AI 分析** — 开启 AI 模式，用更自然的语言描述需求，系统自动理解并查询
- ✅ **导出数据** — 将数据导出为 Excel 表格

> 系统由两大部分组成：**后端**（处理数据存储和查询逻辑）和**前端**（您在浏览器中看到的页面）。

## 🚀 快速启动

### 首次使用

双击项目文件夹中的 **`启动.bat`** 文件即可一键启动。

启动后会自动打开浏览器，显示如下界面：

```
http://localhost:5173/    ← 前端页面（您操作的界面）
http://localhost:8000/    ← 后端服务（自动运行，不用管它）
```

### 关闭系统

直接关闭浏览器标签页和启动的黑窗口即可。

### 再次使用

再次双击 `启动.bat` 即可。

## 🎯 如何使用

### 主界面：智能查询

打开系统后默认进入「智能查询」页面，这是最常用的功能。

**方式一：自然语言查询**
在输入框中输入任意内容，按 `Enter` 键快速查询，例如：

| 输入 | 作用 |
|------|------|
| `69码为6901234567890` | 按69码精确查询 |
| `品牌为飞利浦` | 按品牌查询 |
| `一级品类为办公设备` | 按一级品类查询 |
| `代发价在100到200` | 按价格区间查询 |
| `代发价升序排列` | 按代发价排序 |
| `进货价从低到高` | 按进货价排序 |
| `折扣率降序排列` | 按折扣率从高到低排序 |
| `品牌为飞利浦 代发价在100到200` | 组合条件查询 |

> 提示：按 `Enter` 快速查询 | `Shift+Enter` 换行

也可以直接粘贴微信群里的客户询价消息，系统会自动识别其中的商品信息。

**方式二：筛选查询**
在输入框下方的下拉菜单中选择条件，选择后系统**自动查询**，无需手动点击：

- **第一行**：一级品类 / 品牌 / 二级品类
- **第二行**：代发价 / 备货商谈价 / 进货价 / 零售价 / 折扣率（跨度 100 以内的价格档位）

多个筛选条件会**自动取交集（AND）**，例如同时选「办公设备」+「飞利浦」只显示同时满足两个条件的商品。

**方式三：AI 智能查询**
点击输入框右侧的「AI」开关，输入更自然的语言，系统会用 DeepSeek AI 分析并执行查询。例如：

- "帮我查一下飞利浦品牌代发价在300到500之间的充电宝"
- "列出所有商品按进货价从低到高排序"
- "一级品类是办公设备，品牌是飞利浦的商品"

---

### 数据管理

点击左侧菜单的「数据管理」进入。

#### 查看数据

- 表格显示所有商品的完整字段信息，可拖拽底部滚动条查看隐藏列
- 点击「代发价」列头可排序
- 序号根据当前页码自动计算，删除数据后序号自动连续

#### 缩放表格

表格左上角有缩放滑块（`🔍-` / 拖拽 / `🔍+`），可像 Excel 一样放大缩小，范围 50% ~ 200%。

#### 搜索商品

顶部搜索框输入关键词（快查型号/型号/品牌/产品名称/69码）搜索。

#### 切换每页条数

右下角分页控件可选择每页显示 10、20、50、100、200、500、1000 条。

#### 新增商品

点击「新增商品」按钮，填写表单后保存。快查型号、型号、代发价为必填项。

#### 编辑/删除

- 点击商品行右侧的「编辑」按钮修改
- 点击「删除」按钮删除单条
- 勾选多条后点击「批量删除」

---

### 导入数据

用于将 Excel 表格批量导入系统，支持**一次选择多个文件**同时上传。

1. 点击 **「导入数据」** 按钮
2. 上传 Excel 文件（支持 `.xlsx` / `.xls` / `.csv`，可一次选择多个）
3. 系统自动解析每个文件，识别列名并匹配到数据库字段
4. 在文件列表中点击切换文件，**逐个检查**列映射是否正确，可手动调整
5. 选择重复数据处理策略（所有文件共用同一策略）：
   - **跳过已有**：快查型号已存在则跳过（结果中会列出被跳过的行）
   - **覆盖更新**：快查型号已存在则覆盖更新（结果中会列出被覆盖的行）
   - **报错提示**：快查型号已存在则报错
6. 点击「确认导入」— 导入结果会详细列出每行的处理情况

> ⚠️ 导入必填字段：**快查型号**、**型号**、**代发价**（必须 > 0）

#### 导入注意事项

- 表头最好与系统字段一致（如"快查型号"、"型号"、"代发价"、"品牌"等）
- 系统会自动模糊匹配相似的列名（如"69码"和"条形码"都能识别）
- 导入结果会显示成功/跳过/失败的数量，以及**每行具体处理详情**（包括被跳过和覆盖的记录）

---

### 导出数据

点击「导出数据」按钮，当前筛选条件下的所有数据会导出为一个包含全部字段的 Excel 文件。

## ❓ 常见问题

### Q：页面打不开 / 显示"无法访问此网站"

可能是服务未启动。请关闭所有黑窗口，重新双击 `启动.bat`。

### Q：导入时提示"文件已过期"或报错

每次上传文件后需在**同一会话**中点击确认导入。如果页面停留太久需重新上传。

### Q：查询结果为空

- 检查筛选条件是否过于严格（尝试减少筛选条件）
- 切换到「智能查询」页面，用自然语言搜索试试
- 确认数据管理中确实有数据

### Q：导入后数据错乱或全部失败

- 检查 Excel 列名是否被正确映射
- 必填字段（快查型号、型号、代发价）不能为空
- 代发价必须大于 0
- 查看导入结果中的错误原因列表，修改 Excel 后重试

### Q：切换1000条/页时报错422

这是后端对每页最大条数的限制，已修复为支持到 1000，刷新后重试即可。

### Q：删除了旧数据库后数据丢失

删除 `backend/data.db` 文件会清空所有数据。如果没有备份，需要重新导入 Excel。

### Q：数据显示顺序不对

默认按 ID 升序排列（最早的在最前）。可按「代发价」列头排序。

## 🛠 简易维护

### 目录结构

```
智能报价/
├── 启动.bat                ← 一键启动（双击这个）
├── backend/               ← 后端程序（别动）
│   ├── data.db            ← 数据库文件（所有数据存在这里）
│   └── uploads/           ← 上传的临时文件（自动清理）
└── frontend/              ← 前端程序（别动）
```

### 备份数据

数据库文件位于 **`backend/data.db`**，备份它就是备份所有数据：

1. 关闭系统（关掉所有黑窗口）
2. 复制 `backend/data.db` 到安全位置（如桌面、U盘）
3. 需要恢复时，把备份文件复制回原位置覆盖即可

### 恢复出厂设置

如果想完全重置系统（清空数据回到初始状态）：

1. 关闭所有黑窗口
2. 删除 `backend/data.db` 文件
3. 双击 `启动.bat` 重新启动
4. 系统会自动创建新的空数据库

### 更新系统

如果后续有代码更新：

1. 关闭所有黑窗口
2. 备份 `backend/data.db`（重要！）
3. 用新代码覆盖项目文件
4. 把备份的 `data.db` 复制回 `backend/` 目录
5. 双击 `启动.bat` 启动

| 项目 | 价格（每百万 tokens） |
|------|-------------------|
| 输入（缓存命中） | ¥0.02 |
| 输入（缓存未命中） | ¥1.00 |
| 输出 | ¥2.00 |

> 参考链接：[DeepSeek 官方定价页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)

**每次 AI 查询的大致费用参考（以典型使用场景估算）：**

| 场景 | 输入 tokens 约 | 输出 tokens 约 | 费用约 |
|------|---------------|---------------|-------|
| 简短查询（如"查一下飞利浦充电宝"） | 2,500 | 300 | **¥0.003** |
| 中等查询（复杂组合条件） | 2,500 | 500 | **¥0.004** |
| 长文本粘贴（如整段客户询价消息） | 4,000 | 500 | **¥0.005** |

> 注：以上为缓存未命中时的估算值。若输入内容在缓存中命中，费用可大幅降低（约 98%）。实际费用以 DeepSeek 官方计费为准，价格可能发生变动，请定期查看 [DeepSeek 定价页面](https://api-docs.deepseek.com/zh-cn/quick_start/pricing) 获取最新信息。
