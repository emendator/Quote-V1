## 🤔 这是什么？能做什么？

这是一个 **内部使用的商品管理 + 报价工具**，解决以下实际问题：

| 你的需求 | 系统怎么帮你 |
| --------- | ------------ |
| 手里有一堆 Excel 商品表格，想集中管理 | **导入功能** — 把 Excel 批量导进系统，以后都在这里查 |
| 客户问价，要找某个品牌某价位的商品 | **智能查询** — 像聊天一样输入"飞利浦充电宝100块以下"，自动查出来 |
| 客户要一个报价方案，需要推荐商品组合 | **智能方案** — 输入总价和商品信息（或一句话需求），系统自动组合生成多个方案供选择 |
| 之前做的报价方案找不到了 | **历史方案** — 所有方案自动保存，随时查看、复用、删除 |
| 多个人使用，需要区分权限 | **多级权限** — 最高级管理员 > 管理员 > 用户（数据隔离），另有游客体验模式 |
| 想先体验再注册 | **游客模式** — 一键游客登录，体验核心功能，不保留任何数据，退出自动清除 |

**系统分两部分：**

- **前端** — 你在浏览器里看到的页面（操作界面）
- **后端** — 背后处理数据的程序（启动后自动运行，不用管它）

## 🚀 快速开始

### 第一次使用

1. 打开项目文件夹 `智能报价`
2. **双击** `启动.bat` 文件（一个齿轮图标）
3. 会弹出一个黑窗口（**不要关掉它**），等待几秒钟
4. 浏览器打开后，你会看到 **登录页面**
5. 使用最高级管理员给的邀请码注册

> ⚠️ **黑窗口不能关**（共两个：一个后端一个前端），关了系统就停了。可以最小化到任务栏。
>
> ✅ 后端不会因长时间无操作而自动关闭，它会持续运行直到你关闭终端窗口。

### 关闭系统

- 直接关掉浏览器标签页
- 关掉后端的黑窗口（或在里面按 `Ctrl+C`）
- 再关掉前端的黑窗口

### 再次使用

再次双击 `启动.bat` 即可，之前的**所有数据都还在**。

### 不想注册？一键游客体验

1. 在登录页面点击 **「游客登录（体验模式）」** 按钮
2. 无需邀请码，立即进入系统体验
3. 游客可使用 **智能查询 / 数据管理 / 智能方案** 等核心功能
4. 使用 AI 功能时，在右上角用户菜单 →「API Key 配置」填入自己的 DeepSeek API Key
5. **不保留任何数据**：游客模式下所有数据均为临时数据，退出登录后自动清除全部使用痕迹

### 已部署到云服务器时（网页访问）

如果系统已按部署文档部署到云服务器，则**不需要本地启动**：

1. 打开浏览器，访问 **`http://服务器公网IP:8085`**（例如 `http://***REMOVED-IP***:8085`）
2. 使用管理员分配的账号密码登录即可
3. 公司同事都可以通过该地址访问，数据集中存在服务器上
4. 详细部署与运维见 `deploy/` 目录及 `工作日报/day23.md`

## 🔑 账号与权限

### 三级权限

系统支持三个级别的账号，从高到低：

| 角色 | 说明 | 权限 |
| ------ | ------ | ------ |
| 👑 **最高级管理员** | 系统创建者 | 全部权限、分发所有邀请码 |
| 👤 **管理员** | 由最高级管理员邀请注册 | 管理本公司产品、分发用户邀请码 |
| 👤 **用户** | 由管理员邀请注册 | 仅可使用功能，不可分发邀请码 |
| 🧪 **游客** | 无需注册，登录页一键进入 | 体验核心功能；不保留数据；无用户管理权限 |

> 🧪 **游客模式**：登录页点击「游客登录（体验模式）」即可进入，无需邀请码。可体验智能查询/数据管理/智能方案等核心功能（使用 AI 需自行配置 API Key），**不保留任何数据**，退出登录后自动清除全部使用痕迹。

### 注册新账号

1. 需要先由上级账号创建一个**邀请码**
2. 在登录页面点击「立即注册」
3. 填写用户名、密码、邮箱、邀请码
4. 注册成功后自动登录
5. 首次登录需填写**公司信息**：公司名称 + 公司数据库密码（加入已有公司）

> 💡 最高级管理员登录后 → 在「邀请码管理」页创建邀请码 → 把邀请码发给需要注册的人。

### 公司与数据隔离（重要）

系统按 **公司** 隔离数据，不同公司的商品、方案、用户互不可见。公司的身份凭证是 **公司名称 + 公司数据库密码**：

| 概念 | 说明 |
| ----- | ----- |
| 加入已有公司 | 注册后在「完善公司信息」页填公司名 + 公司数据库密码，验证通过即加入 |
| 新注册公司 | 管理员及以上可选择「新注册公司」，并设置公司数据库密码 |
| 修改公司密码 | 管理员可修改**本公司**密码；最高级管理员可指定公司名修改**任意公司**密码 |
| 归属不可更改 | 绑定公司后无法更换公司 |
| 🧹 无账号公司自动清理 | 某公司下没有任何注册账号时，系统自动删除该公司名、公司密码及其全部业务数据 |

> ⚠️ 公司数据库密码是数据隔离的钥匙，请妥善保管；忘记密码需联系最高级管理员重置。
>
> 🧹 **自动清理**：系统启动时和每半小时会自动检查，删除「没有任何注册账号」的公司（含公司名、公司数据库密码与全部业务数据），避免残留无效公司。

## 🔍 功能一：智能查询（查商品）

这是最常用的功能。打开系统后默认进入这个页面。

### 方法1：直接打字搜索（最快）

在输入框里输入你想找的东西，按 **回车键** 立刻搜索。

**你可以这样搜：**

| 你想做什么 | 输入内容 |
| ----------- | --------- |
| 查某个品牌 | `飞利浦` 或 `品牌为飞利浦` |
| 查某个价格区间 | `代发价在100到200` |
| 查69码 | `69码6901234567890` |
| 按价格排序 | `代发价升序排列` 或 `进货价从低到高` |
| 组合查询 | `飞利浦 代发价在100到200` |
| 粘贴客户消息 | 直接把微信群里的询价文字粘贴进来 |

> 小技巧：按 `Enter` 搜索，`Shift+Enter` 换行。
>
> 💡 **不想打字？** 输入框下方有 **快捷示例**（如 `飞利浦充电宝100块以下`、价格区间、69码、组合查询等），**点击一下**即可自动填入并立刻查询；**「📋 粘贴」按钮**可把你复制好的客户询价文字一键粘进来（系统会弹窗询问浏览器授权，同意即可用）。

### 方法1b：批量快查型号（一次查多个）

切换到 **「批量」模式**，每行输入一个快查型号（换行分隔），系统会分别查询每个型号的代发价等信息，结果按型号分组展示。

```
例如：
K1 pro-追觅
AF10 Lite-追觅
AP10-追觅
```

> ✅ 批量模式支持 **导出**：勾选商品后点击「导出选中」可将所有型号的查询结果汇总到一张 Excel 表格。

### 方法2：用下拉菜单筛选

输入框下面有一排下拉菜单，选择后**自动查询**：

- **第一行**：一级品类 / 品牌 / 二级品类 / 三级品类
- **第二行**：代发价 / 备货商谈价 / 进货价 / 零售价 / 折扣率

多个条件会**同时生效**（取交集），比如选了「办公设备」+「飞利浦」，只显示既是办公设备又是飞利浦的商品。

### 方法3：AI 智能查询（更聪明）

> ⚠️ **需要 DeepSeek API Key**：首次使用 AI 功能前，需在右上角用户菜单 →「API Key 配置」中填入你的 DeepSeek API Key（以 `sk-` 开头）。未配置时将无法启用 AI 模式。

点击输入框旁边的 **AI 开关**（变成黄色），然后用更自然的说法，例如：

- "帮我查一下飞利浦品牌代发价在300到500之间的充电宝"
- "列出所有商品按进货价从低到高排序"
- "一级品类是办公设备，品牌是飞利浦的商品"

> AI 会参考数据库中实际存在的品牌名和品类名来理解你的话，比如你说"插线板"，它会自动匹配到数据库中的"排插"。
>
> AI 查询完成后，输入框下方会显示本次消耗的 tokens 数量。

### 查询结果

- **图片预览**：商品图片会以缩略图显示，鼠标悬停可查看大图
- **排序**：点击列头（如代发价、进货价、零售价、报价更新、折扣率等）可升序/降序排列，空值自动排到最后
- **报价更新**：显示最近一次报价变动日期（去掉时分秒），位于代发价左侧
- **勾选导出**：在表格左侧勾选商品，点击上方的 **「导出选中」** 按钮可将勾选的商品导出为 Excel 文件
- **全选/取消全选**：一键勾选或清空所有商品

### 标记想要的商品

查询结果中，每行商品右侧有一个 **「加入」** 按钮，可将商品标记到本地方案清单（左侧菜单「智能方案」旁会显示数量），方便集中整理想要的商品。

> 💡 实际生成报价方案请在 **「智能方案」** 页进行：用「多块输入」逐项填写，或用「AI 智能输入」一句话让 AI 自动解析生成组合方案。

## 💡 功能二：智能方案（出方案）

当客户需要一份报价方案时使用。你只需告诉系统总价和想要的商品（或一句话需求），系统会**自动组合出多个可行方案**供你选择。

### 输入方式

系统提供**两种输入方式**，在需求输入区下方的「列配置」按钮右侧切换：

| 方式 | 适用场景 | 说明 |
| ---- | -------- | ---- |
| **多块输入** | 需求明确、自己清楚要哪些商品 | 逐项填写总价 + 商品信息块 |
| **AI 智能输入** | 只有一句笼统需求，懒得逐项填 | 粘贴一句话，AI 自动解析（需配置 API Key） |

### 方式1：多块输入

1. **填写总价（必填）** — 并选择限制方式：**小于 / 大于 / 左右**
2. **填写总折扣率（可选）** — 同样支持小于 / 大于 / 左右，也可选「不限」
3. **添加商品信息块** — 点击「添加商品」增加，每个商品块填写：
   - **三级品类（必填）** — 输入关键字可下拉搜索，也可直接选择数据库中已有的三级品类
   - **数量** — 该品类需要几件（同一品类下需为**互不相同的商品**，若该品类可选商品不足，系统会提示调整）
   - **价格限制（可选）** — 小于 / 大于 / 左右 + 金额
   - **折扣率限制（可选）** — 小于 / 大于 / 左右 + 百分比
   - 商品块可展开/收起，折叠后仍显示关键信息（品类 + 数量 + 约束摘要）
4. 点击 **「生成组合方案」**

> 必填项未填写完整时，点击生成会提示具体缺失项（如"总价；第 2 个商品的品类"）。

### 方式2：AI 智能输入

> ⚠️ 需要先配置 DeepSeek API Key（右上角用户菜单 → API Key 配置）。

1. 切换到 **「AI 智能」** 输入方式
2. 在输入框里粘贴客户需求，例如：

   ```
   我要一个价值500的礼盒，包含三个产品，整体折扣率低于70%，产品分别是移动电源、自拍杆、数据线，其中移动电源价值不低于300
   ```

3. 点击 **「生成组合方案」** — AI 会自动解析总价、三级品类、价格/折扣率限制并生成方案
4. 方案列表顶部会显示 AI 解析出的需求摘要和本次消耗的 tokens

#### 不指定品类？（"任意 / 不限"商品）

即使你不限定具体商品，也能让系统帮你出方案。用自然语言说清楚"要几件、大概多少钱、折扣率多少"即可，例如：

```
我需要一个价值500元的礼盒，包含任意三个产品，整体折扣率低于70%
给我配 5000 元以内的随便 4 样商品
```

- 当你使用 **"任意 / 随意 / 不限 / 都可以 / 什么都可以 / 商品"** 等词（或干脆只说要几件"产品"）时，系统会把它理解为**不限定具体品类**的槽位
- 这样的槽位会从**全部有价格的商品**中挑选，且会**分层采样**（低价、中价、高价都会覆盖），而不是只挑最便宜的几个，因此能凑出较高的目标总价
- 若"任意"目标在总价 / 数量上确实无法达成（例如任意 3 件凑满 5000 元），系统同样会给出具体可行的调整建议

### 组合方案结果

- 系统会**自动枚举所有满足条件的商品组合**，一次生成多个方案供选择
- **排序**：默认「智能」排列（总价最接近你输入目标的方案排最前），可切换 升序 / 降序
- 每个方案显示：总金额、商品数量、平均折扣率
- 点击某个方案，右侧 **方案预览** 显示商品明细（可展开/收起）

### 保存与导出

- **保存方案** — 填写方案名称，保存到数据库（可在「历史方案」查看）
- **导出 Excel** — 将方案导出为 Excel 表格（含商品全部字段和图片），文件名 = 方案名称
- **历史方案** — 查看 / 复用 / 删除已保存的方案

### 无方案时的提示（智能方案诊断）

如果找不到符合条件的组合，系统会弹出 **「🤖 智能方案诊断」面板**，根据你的实际商品数据逐项分析无法生成方案的原因，并给出**具体可执行的调整建议**（数值来自商品库真实数据），例如：

- 「总价预算过低：最低组合总价也要 119 元，超出总价上限 5 元。建议：将总价上限提高到 119 元」
- 「总折扣率要求过低：最低也有 52.71%，高于您要求的 5%。建议：将总折扣率要求调高到 52.71% 或以上」
- 「第 1 个品类『挂耳式耳机』价格限制过严：该品类商品价格在 64~178 元之间，请将价格上限/下限调整到该范围内」
- 「第 2 个品类『充电宝』折扣率限制过严：该品类商品折扣率在 56.8%~66.3% 之间」

覆盖场景：**总价过高/过低、总折扣率过高/过低、单个商品价格过高/过低、单个商品折扣率过高/过低、品类无可用商品**等。

**发现没有合适方案时，系统会直接自动把需要调整的输入框高亮**（紫色边框 + 发光闪烁），一眼就能看到该改哪里。每条诊断还配有**醒目的「🚀 一键应用建议」按钮**：点击后系统自动把建议值填入对应的输入框（总价、总折扣率、某个商品的价格/折扣率），你只需再点「生成方案」即可重新出方案；若是"品类无货"，面板会直接给出**更换品类下拉列表**，选好新品类即可重新生成。按建议逐项调整，就能快速逼近可行方案。

## 🧪 游客模式（体验）

### 游客可以做什么

| 功能 | 游客可用 | 说明 |
| ----- | :------: | ----- |

## ❓ 常见问题

### 页面打不开 / 显示"无法访问此网站"

可能是服务没启动。关掉所有黑窗口，重新双击 `启动.bat`。

### 提示「公司名称或公司数据库密码错误」

- 确认公司名称与管理员提供的完全一致（含空格/大小写）
- 确认公司数据库密码输入正确；如遗忘请联系最高级管理员重置

### 提示「账号已过期，已禁止登录」

账号有效期到了。请联系管理员在「用户管理」里为该账号**续期**后再登录。

### 黑窗口报错后自动关闭了

1. 检查是否安装了 Python（见下方"首次使用准备"）
2. 尝试右键 `启动.bat` → 「以管理员身份运行」

### 后端频繁自动关闭

如果后端启动后运行一段时间自动关闭，请检查后端黑窗口中的报错信息。多数情况下重启即可；若频繁崩溃，请确认本机 Python 环境完整，或尝试更新到最新版本。

### 调用 AI 匹配时出现 500 错误

如果使用 AI 匹配时弹出 "Request failed with status code 500"，可能是后端代码未更新。请重启后端确保最新代码生效。

### 查询结果为空

- 检查筛选条件是否太严格（先减少条件试试）
- 确认数据管理中确实有数据（还没导入？）
- 切换到「智能查询」页面，用自然语言搜索试试

### 导入后数据错乱或全部失败

- 检查 Excel 列名是否被正确映射
- 必填字段：**快查型号**、**代发价**（可以为 0，不能为负数）
- **型号** 和 **69码** 已改为选填，没有这些列也能正常导入
- 查看导入结果中的错误原因，修改 Excel 后重试

### 上传 / 导入文件报错（超时、上传失败等）

- 上传或导入文件失败时，系统会给出**清晰的中文提示**（如"上传超时""文件过大""服务器繁忙"等），便于定位原因
- 服务器端已放宽到 **500 MB** 以内文件、并延长上传等待时间；但仍受网络上行速度影响
- 若上传大文件反复失败：优先检查 **本地上行网络**是否稳定（云盘/大附件上传若也慢，多半是本地网络问题）；可尝试关闭占用带宽的软件、改用更小文件分批导入，或换更好的网络后重试

### 数据丢失了

- 先检查 `data/data.db` 文件是否存在（在项目文件夹里）
- 如果文件被删了，数据就丢了，需要重新导入 Excel
- **建议定期备份**这个文件（见下方"数据备份与维护"）

### 游客的数据会保存吗？

**不会。** 游客模式下所有数据都是临时的（商品、方案等），**退出登录后自动清除**；即使直接关闭浏览器，游客会话 24 小时后也会由系统自动清理，不保留任何痕迹。

### 游客看不到「用户管理」菜单？

游客是体验模式，不提供用户管理权限，这是正常现象。如需注册账号、管理用户，请使用管理员邀请码注册正式账号。

### 公司下的账号都被删了，公司数据还在吗？

不会残留。当某公司下没有任何注册账号时，系统会在启动或每半小时自动清理该公司（含公司名、公司数据库密码与全部业务数据）。

## 💾 数据备份与维护

### 所有数据存在哪里？

全部数据保存在 **`data/data.db`** 这一个文件中。备份它就是备份所有数据。

### 如何备份？

1. 关闭系统（关掉黑窗口）
2. 复制 `data/data.db` 到安全位置（桌面、U盘、网盘）
3. 需要恢复时，把备份文件复制回原位置覆盖即可

> 💡 **云服务器部署时**：业务数据在服务器 `/opt/smart-quotation/data/`。可在服务器上执行
> `cd /opt/smart-quotation && tar -czf data-backup-$(date +%Y%m%d).tar.gz data` 打包后下载保存，定期备份。

### 如何重置系统（清空数据）？

1. 关闭所有黑窗口
2. 删除 `data/data.db`
3. 双击 `启动.bat` — 系统会自动创建新的空数据库

### 整个 data 文件夹可以删除吗？

可以。`data` 文件夹（数据库 + 上传/输出缓存）是**运行时数据**，删除后双击 `启动.bat` 会自动重建：

- `data/data.db` — 自动重建为空的数据库（全部数据表 + 超级管理员）
- `data/uploads/`、`data/output/` — 自动重建
- 重建后超级管理员账号**固定不变**：`admin` / `***REMOVED-PASSWORD***` / ***REMOVED-COMPANY***

> ⚠️ 但删除 `data` 会**清空所有业务数据**（商品、用户、方案等），请先按上方步骤备份 `data/data.db`！
>
> 🧪 游客产生的临时数据无需备份：游客账号/公司/商品等会在退出或 24 小时过期后由系统自动清理。

### 如何更新系统版本？

1. 关闭所有黑窗口
2. **先备份** `data/data.db`（重要！否则数据丢失）
3. 用新代码覆盖所有文件
4. 把备份的 `data.db` 复制回 `data/` 目录
5. 双击 `启动.bat`

## 🧑💻 附录：技术架构与开发指南

> 本节面向**开发者 / 维护人员**；普通使用者只需阅读上方“使用说明”即可。  
> 系统由独立的 `backend`（接口与业务）和 `frontend`（浏览器界面）两部分组成，二者通过 HTTP/JSON 通信。

### 1. 技术栈总览

| 层次 | 技术 | 用途 |
| ---- | ---- | ---- |
| 前端框架 | React 18 + TypeScript 5 | 单页应用（SPA），代码在 `frontend/src` |
| 前端构建 | Vite 5 | 开发服务器 / 生产打包 |
| UI 组件 | Ant Design 5 + 自定义 CSS | 表单、表格、弹窗、浅色/深色主题 |
| 路由 / 状态 | React Router 6 + Context | 页面路由；Auth / Theme / PageState 三个全局状态 |
| HTTP 客户端 | axios | 调用后端 `/api/*`（封装 token 注入与错误提示） |
| 后端框架 | FastAPI + uvicorn | REST API，开发默认监听 8000 端口 |
| ORM / 数据库 | SQLAlchemy 2 + aiosqlite | 异步 ORM；数据存 SQLite 单文件 `data/data.db` |
| 数据校验 | Pydantic v2 | 请求 / 响应模型校验（schemas.py） |
| Excel | pandas + openpyxl + lxml | Excel/CSV 解析与导出（含图片嵌入单元格） |
| 认证安全 | pyjwt + passlib(bcrypt) + cryptography | JWT 登录态；密码、用户名、API Key 加密 |
| AI | DeepSeek Chat API（httpx） | AI 智能查询、AI 解析客户需求 |
| 部署 | Nginx + systemd + deploy/*.sh | 公网 8085 → 后端 8008 |

### 2. 请求链路与模块分层

```text
浏览器（React SPA，frontend/）
   │  axios 调用 /api/*（开发环境由 Vite 把 /api 代理到 127.0.0.1:8000）
   ▼
backend/app/routers/  —— HTTP 层：路由、登录/角色权限校验、参数校验
   ▼
backend/app/services/ —— 业务层：查询引擎、组合方案引擎、导入导出、AI 调用等
   ▼
backend/app/models.py + database.py —— ORM 模型与数据库会话
   ▼
data/data.db（SQLite）
```

- **路由**：8 组业务路由挂在 FastAPI 应用上：`/api/auth`（登录注册）、`/api/company`（公司）、`/api/invites`（邀请码）、`/api/products`（商品）、`/api/query`（查询）、`/api/solution`（方案）、`/api/import`（导入）、`/api/column-display`（列配置）；另有 `/api/health` 健康检查与 `/api/cleanup` 手动清理接口。
- **数据隔离**：业务数据都归属某个公司（身份凭证 = 公司名 + 公司数据库密码），所有查询/写入都带 `company_id` / `company_name`，公司之间互不可见；游客拥有独立的临时公司，退出登录或 24 小时过期后自动清除。
- **权限模型**：super_admin > admin > user > guest，路由层通过 `require_company`、`require_company_manager` 等 FastAPI 依赖做拦截。
- **AI 调用**：统一收口在 `services/api_key_service.py`（读个人加密 Key、累计 token）、`services/ai_query_service.py`（AI 查询）、`services/solution_service.py`（AI 解析方案需求）中；每个用户使用自己的 DeepSeek Key，各自计费。
- **静态文件**：后端启动时若检测到 `frontend/dist` 目录，会自动托管前端生产构建产物，实现单端口访问。

### 3. 本地开发启动（命令行方式）

> `启动.bat` 本质就是自动执行下面两条命令；开发人员可直接用命令行以获得实时日志。

后端（终端先进入 backend 目录，使用项目根目录自带虚拟环境里的 Python）：

```powershell
cd backend
..\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

前端（另开一个终端窗口）：


### 4. 常用环境变量

| 环境变量 | 默认值 | 说明 |
| ------- | ------ | ---- |
| JWT_SECRET_KEY | 内置开发默认值 | JWT 与敏感信息加密密钥，**生产环境必须改为随机值** |
| ADMIN_API_KEY | 空 | 启动时自动写入超级管理员的 DeepSeek API Key |
| DATABASE_URL / SYNC_DATABASE_URL | data/data.db | 数据库连接串（默认 SQLite，可换其他库） |
| HOST / PORT | 0.0.0.0 / 8000 | 后端监听地址与端口 |
| CORS_ORIGINS | localhost:5173 | 允许跨域的前端来源（逗号分隔） |
| DEEPSEEK_API_URL / DEEPSEEK_MODEL | DeepSeek 官方接口 | AI 接口地址与模型名 |

> 所有配置集中在 `backend/app/config.py`；启动脚本 `launcher.ps1` 与 `deploy/` 脚本会覆盖部分端口。
