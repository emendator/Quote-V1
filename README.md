## 🤔 这是什么？能做什么？

这是一个 **内部使用的商品管理 + 报价工具**，解决以下实际问题：

| 你的需求 | 系统怎么帮你 |
|---------|------------|
| 手里有一堆 Excel 商品表格，想集中管理 | **导入功能** — 把 Excel 批量导进系统，以后都在这里查 |
| 客户问价，要找某个品牌某价位的商品 | **智能查询** — 像聊天一样输入"飞利浦充电宝100块以下"，自动查出来 |
| 客户要一个报价方案，需要推荐商品组合 | **智能方案** — 输入客户需求，系统自动匹配推荐商品，生成方案文档 |
| 要把商品发布到淘宝/京东/拼多多 | **一键上架** — 勾选商品，选平台，一键发布 |
| 之前做的报价方案找不到了 | **历史方案** — 所有方案自动保存，随时查看、复用、删除 |

**系统分两部分：**

- **前端** — 你在浏览器里看到的页面（操作界面）
- **后端** — 背后处理数据的程序（启动后自动运行，不用管它）

## 🚀 如何启动系统

### 第一次使用

1. 打开项目文件夹 `智能报价`
2. **双击** `启动.bat` 文件（一个齿轮图标）
3. 会弹出一个黑窗口（**不要关掉它**），等待几秒钟
4. 浏览器会自动打开一个页面，显示如下：

```
http://localhost:5173/    ← 这就是系统界面
```

> ⚠️ **黑窗口不能关**，关了系统就停了。可以把它最小化到任务栏。

### 关闭系统

- 直接关掉浏览器标签页
- 关掉那个黑窗口（或在里面按 `Ctrl+C`）

### 再次使用

再次双击 `启动.bat` 即可，之前的**所有数据都还在**。

## 🔍 功能一：智能查询（查商品）

这是最常用的功能。打开系统后默认进入这个页面。

### 方法1：直接打字搜索（最快）

在输入框里输入你想找的东西，按 **回车键** 立刻搜索。

**你可以这样搜：**

| 你想做什么 | 输入内容 |
|-----------|---------|
| 查某个品牌 | `飞利浦` 或 `品牌为飞利浦` |
| 查某个价格区间 | `代发价在100到200` |
| 查69码 | `69码6901234567890` |
| 按价格排序 | `代发价升序排列` 或 `进货价从低到高` |
| 组合查询 | `飞利浦 代发价在100到200` |
| 粘贴客户消息 | 直接把微信群里的询价文字粘贴进来 |

> 小技巧：按 `Enter` 搜索，`Shift+Enter` 换行。

### 方法1b：批量快查型号（一次查多个）

切换到 **「批量」模式**，每行输入一个快查型号，系统会分别查询每个型号的代发价等信息，结果按型号分组展示。

```
例如：
K1 pro-追觅
AF10 Lite-追觅
AP10-追觅
```

### 方法2：用下拉菜单筛选

输入框下面有一排下拉菜单，选择后**自动查询**：

- **第一行**：一级品类 / 品牌 / 二级品类 / 三级品类
- **第二行**：代发价 / 备货商谈价 / 进货价 / 零售价 / 折扣率

多个条件会**同时生效**（取交集），比如选了「办公设备」+「飞利浦」，只显示既是办公设备又是飞利浦的商品。

### 方法3：AI 智能查询（更聪明）

点击输入框旁边的 **AI 开关**（变成黄色），然后用更自然的说法，例如：

- "帮我查一下飞利浦品牌代发价在300到500之间的充电宝"
- "列出所有商品按进货价从低到高排序"
- "一级品类是办公设备，品牌是飞利浦的商品"

> AI 会参考数据库中实际存在的品牌名和品类名来理解你的话，比如你说"插线板"，它会自动匹配到数据库中的"排插"。

### 查询结果

- **图片预览**：商品图片会以缩略图显示，鼠标悬停可查看大图
- **排序**：点击列头（如代发价、进货价、零售价、报价更新等）可升序/降序排列，空值自动排到最后
- **勾选导出**：在表格左侧勾选商品，点击上方的 **「导出选中」** 按钮可将勾选的商品导出为 Excel 文件
- **全选/取消全选**：一键勾选或清空所有商品

### 加入购物车（为方案做准备）

查询结果中，每行商品右侧有一个 **「加入方案」** 按钮。点击后商品会加入购物车，左侧菜单的「智能方案」旁会显示已选数量。

## 💡 功能二：智能方案（出方案）

当客户需要一份报价方案时使用。系统会根据客户需求自动匹配合适的商品。

### 基本流程

1. **输入需求** — 在文本框中输入客户需求，例如：

   ```
   需要一批价格在50-100元的充电宝，品牌飞利浦，用于投标项目
   ```

2. **选择模式**：
   - 不开 AI（默认）：用规则匹配，适合简单明确的需求
   - 开启 AI（点击 AI 开关）：用 AI 理解自然语言，适合复杂需求
3. **点击「分析需求」** — 系统自动筛选匹配的商品
4. **添加商品** — 在候选列表中点击「添加」将商品加入方案
5. **确认方案** — 在右侧方案预览中填写方案名称、备注，调整数量
6. **保存方案** — 方案会存入数据库，之后可以查看和导出
7. **导出文档** — 将方案导出为 Word 文档（.docx），可直接发给客户

### 筛选条件

分析结果出来后，还可以通过上方的下拉菜单进一步筛选：

- 品类 / 品牌筛选
- 各类价格档位（代发价、进货价、零售价等）
- 折扣率范围

### 历史方案

点击「历史方案」按钮，可以：

- **查看** — 所有已保存的方案列表（名称、需求、金额、时间）
- **复用** — 把历史方案的商品重新加载到购物车，修改后保存为新方案
- **删除** — 删除不需要的方案

> 方案数据保存在数据库中，关闭系统也不会丢失。

## 📊 功能三：数据管理（管商品）

点击左侧菜单的「数据管理」进入。这里能看到所有商品的完整信息。

### 查看数据

- 表格显示所有商品，可拖拽底部滚动条查看隐藏列
- 点击「代发价」列头可按价格排序
- 表格左上角有缩放滑块（🔍），可像 Excel 一样放大缩小

### 搜索商品

顶部搜索框输入 **快查型号/型号/品牌/产品名称/69码** 进行搜索。

### 切换每页条数

右下角分页控件可选择每页显示 10、20、50、100、200、500、1000 条。

### 新增商品

点击「新增商品」按钮，填写表单后保存。必填项：**快查型号**、**代发价**。

### 编辑 / 删除

- 点击商品行右侧的「编辑」按钮修改
- 点击「删除」按钮删除单条
- 勾选多条后点击「批量删除」

## 📥 功能四：导入数据（批量录入）

用于把 Excel 表格批量导入系统。

### 操作步骤

1. 点击 **「导入数据」** 按钮
2. 选择 Excel 文件（支持 `.xlsx` / `.xls` / `.csv`，**可一次选多个**）
3. 系统自动解析每个文件，识别列名并匹配到数据库字段
4. 在文件列表中点击切换文件，**逐个检查**列映射是否正确（可手动调整）
5. 选择重复数据处理策略：
   - **跳过已有** — 快查型号已存在则跳过
   - **覆盖更新** — 快查型号已存在则覆盖
   - **报错提示** — 快查型号已存在则报错
6. 点击「确认导入」

### 注意事项

- 表头最好与系统字段一致（如"快查型号"、"型号"、"代发价"、"品牌"等）
- 系统会自动模糊匹配相似的列名（如"69码"和"条形码"都能识别）
- 必填字段：**快查型号**、**代发价**（可以为 0，不能为负数）
- 导入结果会显示成功/跳过/失败的数量和每行详情

## ☁️ 功能六：平台管理 & 一键上架

## ❓ 常见问题

### 页面打不开 / 显示"无法访问此网站"

可能是服务没启动。关掉所有黑窗口，重新双击 `启动.bat`。

### 黑窗口报错后自动关闭了

1. 检查是否安装了 Python（见下方"首次使用准备"）
2. 尝试右键 `启动.bat` → 「以管理员身份运行」

### 查询结果为空

- 检查筛选条件是否太严格（先减少条件试试）
- 确认数据管理中确实有数据（还没导入？）
- 切换到「智能查询」页面，用自然语言搜索试试

### 导入后数据错乱或全部失败

- 检查 Excel 列名是否被正确映射
- 必填字段（快查型号、代发价）不能为空
- 代发价可以为 0（不能为负数）
- 查看导入结果中的错误原因，修改 Excel 后重试

### 数据丢失了

- 先检查 `backend/data.db` 文件是否存在（在项目文件夹里）
- 如果文件被删了，数据就丢了，需要重新导入 Excel
- **建议定期备份**这个文件（见下方"数据备份与维护"）

## 💾 数据备份与维护

### 所有数据存在哪里？

全部数据保存在 **`backend/data.db`** 这一个文件中。备份它就是备份所有数据。

### 如何备份？

1. 关闭系统（关掉黑窗口）
2. 复制 `backend/data.db` 到安全位置（桌面、U盘、网盘）
3. 需要恢复时，把备份文件复制回原位置覆盖即可

### 如何重置系统（清空数据）？

1. 关闭所有黑窗口
2. 删除 `backend/data.db`
3. 双击 `启动.bat` — 系统会自动创建新的空数据库

### 如何更新系统版本？

1. 关闭所有黑窗口
2. **先备份** `backend/data.db`（重要！否则数据丢失）
3. 用新代码覆盖所有文件
4. 把备份的 `data.db` 复制回 `backend/` 目录
5. 双击 `启动.bat`
