## 🧭 项目简介

智能报价系统是一个**自托管**的商品目录与报价工具：把散落在 Excel 里的商品数据集中入库，用自然语言或下拉条件快速查价，并按「总价 + 品类 + 价格/折扣率约束」自动组合出多套可执行的报价方案。

系统由两部分组成，二者通过 HTTP/JSON 通信：

- **frontend/** — 浏览器界面（React + TypeScript 单页应用）
- **backend/** — 接口与业务逻辑（FastAPI + SQLite）

所有数据保存在本地单个 SQLite 文件中，不依赖任何外部数据库或云服务；AI 功能为**可选**，由使用者自行配置自己的 DeepSeek API Key，不配置也可完整使用非 AI 功能。

> 定位说明：这是一个通用型的报价/组合工具，代码中不包含任何业务数据。仓库中**不附带**示例商品数据，请自行导入。

## ✨ 功能特性

| 能力 | 说明 |
| --- | --- |
| 商品管理 | 商品增删改查、批量删除、分页、表头筛选、链接列、表格缩放、列显示自定义（顺序/宽度/表头名） |
| Excel 批量导入 | 支持 `.xlsx` / `.xls` / `.csv`，可一次选择多个文件；自动模糊匹配表头与系统字段，支持人工调整列映射；重复数据处理策略可选「跳过 / 覆盖 / 报错」，并输出逐行成功、跳过、失败明细 |
| 数据导出 | 商品库导出、查询结果导出、方案导出，均为 `.xlsx`；图片以「嵌入单元格」方式写入（随单元格移动缩放，非浮动图片） |
| 规则智能查询 | 把输入文本解析为结构化条件：69 码、型号、品牌、品类、各类价格区间与折扣率、排序、模糊搜索 |
| 批量快查型号 | 一次提交多个型号（按行分隔），结果按型号分组展示并可导出 |
| AI 智能查询 | 调用 DeepSeek 将自然语言转成查询意图（例如「飞利浦代发价 300–500 的充电宝」），并显示本次 token 消耗 |
| 组合报价方案 | 在总价、总折扣率、各品类数量与限价约束下枚举可行组合，按接近目标的程度排序；支持「不限定品类」（任意/不限）槽位并从全库分层采样 |
| 无方案诊断 | 无可行组合时逐项分析原因（总价过高/过低、折扣率越界、单品类价格区间过窄、品类无货），给出数值来自真实数据的调整建议，并支持「一键应用建议」回填输入框 |
| 方案管理 | 方案保存 / 历史方案查看复用删除 / 导出 Excel / 上级组织推荐方案 |
| 多租户隔离 | 业务数据按「公司（组织）」隔离，不同组织商品、方案、用户互不可见；组织身份凭证为「公司名称 + 公司数据库密码」 |
| 三级权限 + 邀请码 | 超级管理员 > 管理员 > 普通用户；邀请码一次性使用，可设置有效天数、续期、删除（删除已使用的邀请码会级联清理该账号及其数据） |
| 游客体验模式 | 登录页一键进入独立临时组织，可体验查询/方案/数据管理；退出即清理，会话最长 24 小时 |
| 自动清理 | 定时清理过期上传缓存；自动删除「名下无任何注册账号」的空组织及其数据 |
| 界面主题 | 浅色 / 深色主题一键切换并持久化，登录页亦有切换入口 |

## 🚀 快速开始

### 环境要求

| 依赖 | 版本 | 说明 |
| --- | --- | --- |
| Python | 3.9+ | 后端运行环境（依赖版本要求，见 `backend/requirements.txt`） |
| Node.js | 18+（LTS） | 前端开发与构建 |
| PowerShell | Windows PowerShell 5.1+ | 仅一键启动脚本 `启动.bat` 需要（Windows 10+ 自带） |

> 一键启动脚本为 Windows 专用；macOS / Linux 请使用下方的「手动启动」。

### 方式一：Windows 一键启动

1. 确认已安装 Python 与 Node.js，并已加入 `PATH`
2. 双击项目根目录的 **`启动.bat`**
3. 脚本会自动完成：检测 Python/Node → 创建或修复 `.venv` → 安装后端依赖（`pip install -r backend/requirements.txt`）→ 安装前端依赖（`npm install`）→ 启动后端（8000 端口）→ 等待健康检查通过 → 启动前端开发服务器（5173 端口）→ 打开浏览器
4. 浏览器打开后即为登录页；首次使用请先按「首次初始化」创建实例管理员

> 启动过程中会保留两个控制台窗口（后端、前端），**关闭窗口即停止服务**；首次运行因安装依赖会较慢。

### 方式二：手动启动（跨平台）

后端（在 `backend/` 目录下，使用已装好依赖的 Python 环境）：

```bash
cd backend
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

前端（另开一个终端，在 `frontend/` 目录下）：

```bash
cd frontend
npm install    # 仅首次或依赖变化时执行
npm run dev    # 打开 http://localhost:5173
```

- 开发环境下 Vite 会把 `/api` 代理到 `http://127.0.0.1:8000`（见 `frontend/vite.config.ts`）
- 接口文档（Swagger UI）：<http://127.0.0.1:8000/docs>
- 健康检查：<http://127.0.0.1:8000/api/health>

### 生产构建（单端口运行）

```bash
cd frontend
npm run build
```

后端启动时会检测 `frontend/dist` 是否存在：存在则直接托管该构建产物，从而可用单一端口访问前后端。

### 首次初始化

首次启动会自动创建数据库、数据表以及一个**超级管理员账号和其所属组织**。这些初始值定义在 `backend/app/config.py` 的 `SUPER_ADMIN_*` 常量中：

> ⚠️ **部署前必须修改** `SUPER_ADMIN_USERNAME`、`SUPER_ADMIN_PASSWORD`、`SUPER_ADMIN_COMPANY` 等初始值（或改造为从环境变量读取）。仓库中的默认值仅供本地试跑，请勿在生产环境沿用。

初始化后：

1. 用超级管理员账号登录
2. 在「用户管理」页创建**邀请码**（一级邀请码 → 管理员；二级邀请码 → 普通用户）
3. 把邀请码发给使用者，对方在登录页「立即注册」填写用户名、密码、邮箱与邀请码
4. 注册后需在「完善公司信息」页加入已有组织（填写组织名称 + 组织数据库密码）或新建组织

## ⚙️ 配置说明

所有配置集中在 `backend/app/config.py`，均可通过环境变量覆盖。

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `DATABASE_URL` | `sqlite+aiosqlite:///<项目>/data/data.db` | 异步数据库连接串 |
| `SYNC_DATABASE_URL` | `sqlite:///<项目>/data/data.db` | 同步数据库连接串（建表、迁移、种子数据使用） |
| `HOST` | `0.0.0.0` | 后端监听地址 |
| `PORT` | `8000` | 后端监听端口 |
| `CORS_ORIGINS` | `http://localhost:5173,http://127.0.0.1:5173` | 允许跨域的前端来源，逗号分隔 |
| `JWT_SECRET_KEY` | 仅用于本地开发的固定默认值 | JWT 签名密钥，**同时用于派生敏感字段（用户名、API Key）的加密密钥**。生产环境必须设为随机值 |
| `ADMIN_API_KEY` | 空 | 若设置，首次启动时会写入超级管理员的 DeepSeek API Key（**从环境变量读取，不写入代码**） |
| `DEEPSEEK_API_URL` | `https://api.deepseek.com/v1/chat/completions` | AI 接口地址 |
| `DEEPSEEK_MODEL` | `deepseek-chat` | AI 模型名 |

其他与运行相关的常量（同样在 `config.py` 中）：

| 常量 | 值 | 说明 |
| --- | --- | --- |
| `DATA_DIR` | `<项目根>/data` | 运行时数据目录（数据库、上传缓存、导出缓存） |
| `UPLOAD_DIR` / `OUTPUT_DIR` | `data/uploads` / `data/output` | 上传临时文件与导出输出目录，不存在时自动创建 |
| `MAX_UPLOAD_SIZE` | 50 MB | 单次上传大小上限（后端校验；反向代理层还应配置不小于该值的 `client_max_body_size`） |
| `ALLOWED_EXTENSIONS` | `.xlsx` `.xls` `.csv` | 允许导入的文件类型 |
| `JWT_ALGORITHM` / `JWT_ACCESS_TOKEN_EXPIRE_MINUTES` | `HS256` / 1440 | 登录令牌算法与有效期（24 小时） |

> 环境变量示例（仅供参考，请勿把真实密钥提交进版本库）：
>
> ```bash
> export JWT_SECRET_KEY="$(python -c 'import secrets;print(secrets.token_urlsafe(48))')"
> export CORS_ORIGINS="https://your-domain.example"
> export ADMIN_API_KEY="<你的 DeepSeek API Key>"
> ```

## 📘 使用说明

### 核心流程

**导入 → 查询 → 出方案 → 导出**。

1. **导入数据**：进入「导入数据」，选择一个或多个 Excel/CSV，逐个检查列映射与重复策略后确认导入。必填字段为「快查型号」与「代发价」（代发价可为 0，不可为负）；「型号」「69 码」等为选填。
2. **智能查询**：「智能查询」页支持三种方式 —— 直接输入文本回车搜索、使用下拉条件筛选（多条件取交集）、或打开 AI 开关用自然语言描述。查询结果支持排序、图片预览、勾选导出，以及把商品「加入」方案清单。
3. **智能方案**：「智能方案」页用「多块输入」逐项填写总价/折扣率/各品类数量与限制，或用「AI 智能输入」粘贴一段需求文本由 AI 解析。系统枚举可行组合并排序，可保存到历史方案或导出 Excel。若无可行组合，会给出诊断面板与「一键应用建议」。
4. **导出**：三个入口均可导出 `.xlsx` —— 商品库、查询结果、方案明细。

### 权限与组织隔离

| 角色 | 来源 | 能力 |
| --- | --- | --- |
| 超级管理员 | 系统首次初始化自动创建 | 全部权限；可创建一级邀请码；可修改任意组织的数据库密码 |
| 管理员 | 由超级管理员用一级邀请码邀请 | 管理本组织商品与数据；可创建二级邀请码 |
| 用户 | 由管理员用二级邀请码邀请 | 使用查询/方案/数据管理，不可分发邀请码 |
| 游客 | 登录页一键进入 | 体验核心功能；无用户管理；退出即清理 |

- 组织身份凭证为 **组织名称 + 组织数据库密码**，绑定后不可更换；忘记密码需由超级管理员重置。
- 低权限账号在查询与方案结果中，还会看到来自**邀请链上级组织**的推荐商品/推荐方案（标注来源组织），仅供参考，采购需自行与来源组织对接。

### AI 功能（可选）

- 需要在右上角用户菜单 →「API Key 配置」中填入自己的 DeepSeek API Key；Key 在数据库中以**加密方式**存储。
- 每次 AI 操作后会显示本次消耗的 token 数，配置弹窗内可查看累计消耗。
- 不使用 AI 模式时功能完全免费；AI 调用按 DeepSeek 官方定价计费，费用由该 Key 的持有者承担。当前定价见 [DeepSeek 官方文档](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)。

### 游客模式

每位游客拥有独立的临时组织，数据与其他组织互不可见；退出登录时清理本次会话数据，即使直接关闭浏览器，也会在会话过期（24 小时）后由后台清理。

## 🔌 API 概览

后端由 FastAPI 提供 REST 接口，Swagger UI 位于 `/docs`，OpenAPI JSON 位于 `/openapi.json`。路由按业务分组（`backend/app/routers/`）：

| 前缀 | 职责 |
| --- | --- |
| `/api/auth` | 注册、登录、当前用户信息、完善组织信息、修改密码、配置/查询个人 API Key、游客登录与退出清理 |
| `/api/company` | 绑定组织（加入已有 / 新建）、修改组织数据库密码、清理空组织 |
| `/api/invites` | 邀请码创建、列表、校验、续期、删除（含级联清理） |
| `/api/products` | 商品分页与筛选、详情、增删改、批量删除、导出、品类/品牌/筛选选项、推荐商品 |
| `/api/query` | 规则查询、AI 查询、批量型号查询、查询结果导出 |
| `/api/solution` | 方案分析生成、保存、导出、历史方案、推荐方案 |
| `/api/import` | 上传解析并返回预览与列映射、确认导入 |
| `/api/column-display` | 列显示配置的读取与保存、可用列清单 |
| `/api/health`（GET）、`/api/cleanup`（POST） | 健康检查、手动触发清理 |

除注册/登录/游客等公开接口外，请求需携带 `Authorization: Bearer <token>`。

## 🚢 生产部署

`deploy/` 目录提供一套 Nginx + systemd 的部署示例（Ubuntu）：

| 文件 | 作用 |
| --- | --- |
| `deploy/deploy.sh` | 一键部署：安装依赖、构建前端、配置 Nginx 与 systemd、放行端口 |
| `deploy/nginx.conf` | 站点配置模板：公网端口反向代理到后端（默认后端 127.0.0.1:8008），并放宽上传体积与超时 |
| `deploy/smart-quotation.service` | systemd 单元：后端开机自启、崩溃自愈 |
| `deploy/update.sh` | 更新脚本：修正权限 → 重新构建前端 → 重启后端 |

使用前请按自己的域名、端口与路径修改这些模板中的占位值（脚本内包含需要替换的端口与安装路径）。生产环境另需注意：

- `JWT_SECRET_KEY` 必须设为随机值（见 [安全与隐私](#-安全与隐私)）
- 修改 `SUPER_ADMIN_*` 初始管理员信息
- 反向代理的 `client_max_body_size` 应与后端 `MAX_UPLOAD_SIZE` 匹配
- 对外暴露时务必启用 HTTPS

> 部署模板仅作为示例，未针对所有发行版与环境验证，请按自身环境调整后再上线。

## 💾 数据与备份

- 全部业务数据保存在 **`data/data.db`**（SQLite 单文件）：商品、用户、组织、邀请码、方案、列配置、导入日志。
- 备份即复制该文件；恢复时用备份文件覆盖回原位。
- `data/uploads/`（上传临时缓存）与 `data/output/`（导出缓存）可随时删除，系统会重建并由后台定时清理。
- 删除整个 `data/` 目录会**清空全部业务数据**，重启后数据库会被重建为空白库并重新写入初始管理员。

```bash
# 备份示例（先停止服务，保证文件一致）
tar -czf data-backup-$(date +%Y%m%d).tar.gz data
```

## 🔒 安全与隐私

- **不内置任何密钥**。AI 能力使用每位用户自己配置的 DeepSeek API Key；Key 以加密形式存储，不参与任何明文日志输出。
- **生产环境必须设置 `JWT_SECRET_KEY` 为随机值**。该密钥不仅用于签发登录令牌，也用于派生敏感字段的加密密钥；沿用默认值会导致令牌可被伪造、已存储的密钥可被解密。
- **必须修改初始管理员账号与组织信息**（`config.py` 中的 `SUPER_ADMIN_*`），不要沿用代码中的默认值。
- 口令使用 bcrypt 哈希存储；用户名等敏感字段加密存储，并用 HMAC 支持等值查询。
- 多租户隔离：所有业务读写均带组织归属，跨组织不可见。
- 请勿把 `.env`、密钥文件、`data/` 目录或任何包含真实数据的表格提交到版本库；建议在贡献流程中加入密钥扫描（如 gitleaks）。
- 部署到公网时建议：启用 HTTPS、限制管理入口访问范围、定期备份并轮换密钥。
- 本项目会处理商品与价格等业务数据，请自行确认数据的合规来源与使用授权。

## ❓ 常见问题

**页面打不开 / 提示无法访问此网站**
服务可能未启动。重新运行 `启动.bat`（或手动启动前后端），并确认两个进程都处于运行状态。

**提示「公司名称或公司数据库密码错误」**
确认组织名称与管理员提供的一致（含空格与大小写），以及组织数据库密码是否正确；遗忘需由超级管理员重置。

**提示「账号已过期，已禁止登录」**
账号有效期已到，请联系管理员在「用户管理」中续期。

**启动脚本报错后窗口自动关闭**
确认已安装 Python 3.9+ 与 Node.js 18+ 且加入 `PATH`；可尝试右键 `启动.bat` →「以管理员身份运行」，或在 PowerShell 中直接执行 `launcher.ps1` 查看完整日志。

**查询结果为空**
条件可能过严（先减少筛选条件）；确认「数据管理」中已有数据；也可切换到自然语言搜索。

**导入后数据错乱或全部失败**
检查 Excel 列名是否被正确映射；必填字段为「快查型号」「代发价」；查看导入结果中的逐行错误原因后修正表格重试。

**上传/导入报错（超时、文件过大等）**
界面会给出中文错误提示。后端单文件上限由 `config.py` 的 `MAX_UPLOAD_SIZE` 控制（默认 50 MB），反向代理层也要放开同等或更大的体积与超时；大文件失败也可能与本地上行网络有关，可分批导入。

**AI 功能报错或无法启用**
确认已在用户菜单中配置有效的 DeepSeek API Key；500 类错误可先重启后端确认代码为最新版本。

**数据丢失了**
检查 `data/data.db` 是否还在；该文件被删除且无备份时数据无法恢复，请定期备份。

**游客的数据会保留吗**
不会。退出登录即清理；直接关闭浏览器也会在会话过期（24 小时）后由系统清理。

**组织下的账号都被删除了，数据还在吗**
不会残留。系统启动时及后台定时任务会清理「名下无任何账号」的空组织及其数据。
